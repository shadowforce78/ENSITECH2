Analyse du besoin

L'objectif était de concevoir un système de chiffrement et de déchiffrement basé sur le chiffre de Vigenère. Ce chiffrement polyalphabétique utilise une clé répétée pour décaler chaque lettre du texte clair, ce qui le rend plus résistant que le simple chiffre de César aux attaques par analyse de fréquence.

Le travail demandé consistait à restructurer un programme existant en séparant la logique métier (chiffrement) du programme principal (saisies/affichages), selon les principes de la programmation orientée objet.

Architecture du projet

Le programme est organisé en deux fichiers :

Fichier Rôle
Program.cs Programme principal : saisie du texte et de la clé, appel des méthodes, affichage des résultats.
Vigenere.cs Classe métier : contient toute la logique de chiffrement/déchiffrement. Ne fait aucune saisie ni affichage.

Superposition de la clé — méthode SuperposeKey

La première étape du chiffre de Vigenère consiste à répéter la clé sous le texte clair. Les caractères non-lettres (espaces, ponctuation) sont conservés tels quels et ne consomment pas de position dans la clé. 

public string SuperposeKey(string cle, string texte)
{
    VerifierCle(cle);
    string resultat = "";
    int position = 0;

    for (int i = 0; i < texte.Length; i++)
    {
        if (char.IsAsciiLetter(texte[i]))
        {
            resultat += cle[position % cle.Length];
            position++;
        }
        else
        {
            resultat += texte[i];
        }
    }
    return resultat;
}

Exemple : texte = "les gaulois", clé = "cle"

Clécle cleclec

Chiffrement — méthode Chiffrer

Pour chaque lettre, on calcule son rang (0–25) et celui de la lettre de clé correspondante, puis on additionne les deux modulo 26. Les caractères non-lettres sont recopiés sans modification. 

public string Chiffrer(string texte, string cle)
{
    string cleRepetee = SuperposeKey(cle, texte);
    string resultat = "";

    for (int i = 0; i < texte.Length; i++)
    {
        if (char.IsAsciiLetter(texte[i]))
        {
            int lettre = char.ToLower(texte[i]) - 'a';
            int decalage = char.ToLower(cleRepetee[i]) - 'a';
            resultat += (char)('a' + (lettre + decalage) % 26);
        }
        else
        {
            resultat += texte[i];
        }
    }
    return resultat;
}

Formule : chiffré = (lettre + décalage) mod 26

Déchiffrement — méthode Dechiffrer

L'opération inverse : on soustrait le rang de la clé au rang de la lettre chiffrée, en ajoutant 26 avant le modulo pour éviter les valeurs négatives. 

public string Dechiffrer(string texte, string cle)
{
    string cleRepetee = SuperposeKey(cle, texte);
    string resultat = "";

    for (int i = 0; i < texte.Length; i++)
    {
        if (char.IsAsciiLetter(texte[i]))
        {
            int lettre = char.ToLower(texte[i]) - 'a';
            int decalage = char.ToLower(cleRepetee[i]) - 'a';
            resultat += (char)('a' + (lettre - decalage + 26) % 26);
        }
        else
        {
            resultat += texte[i];
        }
    }
    return resultat;
}

Formule : clair = (lettre - décalage + 26) mod 26

Validation de la clé — méthode VerifierCle

Une méthode privée vérifie que la clé n'est pas vide et ne contient que des lettres ASCII. En cas d'erreur, une ArgumentException est levée, interceptée dans Program.cs par un bloc try/catch. 

private void VerifierCle(string cle)
{
    if (string.IsNullOrEmpty(cle))
        throw new ArgumentException("La clé ne doit pas être vide.");

    for (int i = 0; i < cle.Length; i++)
    {
        if (!char.IsAsciiLetter(cle[i]))
            throw new ArgumentException("La clé ne doit contenir que des lettres (a-z).");
    }
}

Programme principal — Program.cs

Le programme crée un objet Vigenere, demande à l'utilisateur un texte et une clé, puis affiche la clé superposée, le texte chiffré et le texte déchiffré (vérification aller-retour). La gestion d'erreurs est assurée par un try/catch sur ArgumentException. 

Vigenere outil = new Vigenere();

Console.Write("Texte à chiffrer : ");
string texte = Console.ReadLine() ?? "";

Console.Write("Clé : ");
string cle = Console.ReadLine() ?? "";

try
{
    string texteChiffre = outil.Chiffrer(texte, cle);
    Console.WriteLine("Clé superposée : " + outil.SuperposeKey(cle, texte));
    Console.WriteLine("Texte chiffré : " + texteChiffre);

    string texteDechiffre = outil.Dechiffrer(texteChiffre, cle);
    Console.WriteLine("Texte déchiffré : " + texteDechiffre);
}
catch (ArgumentException e)
{
    Console.WriteLine("Erreur : " + e.Message);
}

Bilan

Le programme est pleinement fonctionnel : il chiffre et déchiffre correctement un message avec le chiffre de Vigenère. L'approche par arithmétique modulaire (addition/soustraction de rangs mod 26) est plus légère qu'une grille 26×26 en mémoire et produit un résultat équivalent. La séparation classe/programme respecte les principes de la POO : la classe Vigenere ne dépend d'aucune entrée/sortie console et pourrait être réutilisée dans un autre contexte (application graphique, API, etc.).
